Maintenance & Admin Operations

To preserve web server responsiveness and ensure auditability, long-running batch operations are executed via the Typer CLI:

Live CCRAS Web Scraping
herbal-almanac scrape dravya --max-plants 25

Web scraping involves external network latency, retries, and rate limits; running via CLI prevents HTTP worker starvation.

Offline Stage C Backfill & Migration
herbal-almanac upgrade-stage-c --database <path> --yes

Transforms uncurated raw attributes into classical 6-domain concept claims with deduplication triggers.

Database Diagnostics & Smoke Test
python scripts/make_demo_db.py --output demo.db

Constructs a fully seeded offline demonstration database with Stage C features enabled in seconds.
